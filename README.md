# EzWoW-SpellControl

## English

**Buff, cleanse, and crowd-control board** for WoW Forever (Interface 16001).

- Install the `EzWoW-SpellControl` addon folder under `Interface/AddOns/`.
- The complete source distribution includes detailed features, settings, changelog and license information.
- In-game compatibility still requires testing.
