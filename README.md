# EzWoW-SpellControl

> 스마트 주문 관리 · WoW Forever 애드온

파티 버프, 디버프 해제, 군중 제어 주문을 모아 표시 기능을 제공하는 월드 오브 워크래프트 애드온입니다.

## 안내

- 대상 클라이언트: WoW Forever (애드온 TOC 기준 Interface 16001)
- 설치: 배포된 애드온 폴더를 게임의 `Interface/AddOns/`에 복사하고 게임을 재시작합니다.
- 설정과 명령어: 소스 패키지에 포함된 상세 사용 설명서를 참고하세요.
- 버전 및 변경사항: `CHANGELOG.md`
- 라이선스: 저장소의 `LICENSE` 또는 `LICENSE.txt`를 확인하세요.

## 개발 및 호환성

EzWoW 애드온들은 각각 독립적으로 관리합니다. 일부 애드온은 설치되어 있는 다른 EzWoW 애드온과 선택적으로 연동할 수 있습니다. 게임 내 기능과 호환성은 실제 클라이언트에서 별도 검증이 필요합니다.
